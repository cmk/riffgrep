# plan-2026-05-07-01.md - Template workflow port

## Goal
Port the current `template-rust` workflow contract into `riffgrep` without touching product search/indexing scripts.

## Dependency Graph

```
T1 -> T2 -> T4
T1 -> T3 -> T4
```

## Tasks

### T1 - Rename workflow scripts to the current contract

- Problem or motivation: `riffgrep` still uses the older `local_review.sh`, `safe_merge.sh`, `autosquash.sh`, `review_path.sh`, `extract_pr_body.sh`, `pull_reviews.py`, and `reply_review.py` names.
- Solution / implementation approach: replace those entrypoints with the current `pr_*`, `git_*`, and shared GitHub helper scripts from `template-rust`.
- Types or API surface: workflow scripts under `scripts/`, leaving Lua, SQL, embedding, and indexing scripts unchanged.

### T2 - Update hooks and CI gates

- Problem or motivation: the current template separates cheap pre-commit checks from expensive pre-push checks and runs Python workflow tests in CI.
- Solution / implementation approach: update `.githooks`, preserve repository-specific CI behavior, and add the Python unittest lane.
- Types or API surface: `.githooks/`, `.github/workflows/ci.yml`, and `tests/test_workflow_state.py`.

### T3 - Update docs and command playbooks

- Problem or motivation: `AGENTS.md`, `doc/workflow.md`, `.claude/commands`, and workflow prose refer to old script names and `.watch-pr`.
- Solution / implementation approach: update workflow-sensitive documentation and command playbooks to the current `pr_*` / `.pr-watch` contract.
- Types or API surface: repo docs and Claude command markdown files.

### T4 - Verify the workflow port

- Problem or motivation: this is infrastructure, so regressions show up as broken scripts or stale gates rather than Rust API failures.
- Solution / implementation approach: run shell syntax checks, Python unittest discovery, PII checks, and lightweight workflow-state probes before final review.
- Types or API surface: local test commands only.

- Design deviations: the template layer-check hook was not copied because `riffgrep` does not have a layer checker; the Claude and Git hooks run only the checks this repo actually owns.

- Recommendations: keep product Python/Lua/SQL scripts separate from workflow helpers in future script naming sweeps.
